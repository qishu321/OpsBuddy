# 工作流与知识库使用指南

版本：桌面版 0.3.1，2026-10-15。

## 知识库

1. 在左侧打开「知识库」，选择当前项目并创建资料库。
2. 点击「导入本机资料」打开 Windows 文件选择器，或用「引用项目文件」将已有材料加入索引。
3. 支持 DOCX、PPTX、XLSX、CSV、TSV、文本 PDF、TXT、Markdown。解析失败的文件会显示原因，不会标为可检索。
4. 在检索框输入主题或关键词，结果展示文件名、片段号、PDF 物理页码及原文；点击「查看来源」阅读切片。
5. 工作台输入框里的「引用知识库」可选择资料来源。旧自定义配置迁移为 Skill 后仍保留关联知识库。
6. 原材料发生变化时点击「重建索引」。移出索引不会删除文件，历史任务仍保留当时引用的原文和哈希。

知识库按项目隔离。当前使用本地中文二元词片段和英文词检索，每段 600 字符、相邻重叠 100 字符，不需要额外模型或 embedding Key。未提供向量语义检索、扫描件 OCR。单次最多导入 16 个、总计 32 MB 的材料，单份索引正文最多 100 万字符。

选择 AI 模型并确认发送授权后，检索命中的片段会发送到该模型；本地模式只按规则整理，不会做语义推理。没有命中时不会凭空生成资料引用。

## 工作流画布

在「工作流」创建空白流程，或选择「资料到汇报」「从知识库撰写」「条件分支」模板。模板生成可编辑画布，保存后即可执行。

空白画布中点击 Agent、知识检索、办公工具或汇合节点，会自动将第一个处理节点接入开始与结束之间；条件节点只接入入口，TRUE/FALSE 需手动配置。底部工具条提供缩放、适应画布、整理布局与小地图开关。整理布局按依赖分层排列，支持撤销/重做；仍需点击保存才能持久化。

| 节点 | 配置与作用 |
| --- | --- |
| 开始 | 取得执行时输入的任务要求与附件 |
| Agent | 选择 Skills、模型、交付格式和提示词；生成真实成果文件 |
| 知识检索 | 选择知识库与检索词，将命中原文和来源传给下游 |
| 条件分支 | 根据任务输入/上游文字是否包含指定文字，或是否存在上游文件，选择 TRUE/FALSE |
| 办公工具 | 调用本地文件处理器，支持现有文档、表格、PDF 和分类打包规则 |
| 汇合 | 等待有效上游完成，选择全部成功或允许部分成功 |
| 结束 | 收集有效路径的文件作为最终成果 |

点击左侧按钮添加节点；拖动节点调整位置。从右侧出口连到另一节点的左侧入口。选中节点后在右侧修改参数；条件节点有两个出口。可撤销/重做，选中连线后 Delete 删除；开始与结束节点受保护，不能通过 Delete 删除。

提示词支持 `{{input}}`（本次任务要求）与 `{{context}}`（上游文字）。上游文件自动传递，不用手填磁盘路径。知识检索词支持 `{{input}}`。当前没有任意代码执行节点。

保存前会检查节点/连线、缺失配置、环路、不可达节点和结束路径。每次保存递增版本。已有运行使用提交时的流程、角色/技能/模型和命中资料快照，后续编辑不会改写历史。

## 执行与运行记录

1. 点击「执行」，输入任务要求并选择附件；可通过原生文件选择器添加本机材料。
2. 若节点配置了模型，需要确认将内容及引用资料发送到这些模型。没有模型的节点执行本地规则。
3. 执行时可查看运行快照，每个节点显示待执行、执行中、成功、失败、跳过或停止。
4. 点击 Agent 节点可打开对应任务和成果；最终文件可直接另存到本机。
5. 「运行记录」保留各次运行的版本、输入、分支选择、节点任务、错误、资料引用与成果。停止流程会取消子任务；已有文件仍保留。

分叉连线可并行运行，实际办公 Agent 最多同时 3 个；单流程最多 40 个节点、120 条连线，总时限 10 分钟。当前只支持无环图，不支持自由循环、定时触发、检查点续跑或自动费用预算。

「有效上游全部成功」会阻止失败路径继续；「允许部分成功」在至少一个有效分支成功时汇集已有成果，并将整个流程标为部分完成。被条件跳过的路径不会阻塞汇合。

退出应用会中断运行。下次启动显示中断记录，不会静默重新执行模型调用。手动重新执行会创建新运行；没有声称已实现失败节点续跑。

## 无需模型的体验路径

创建知识库，导入包含“住宿报销标准：每晚不超过 450 元”的 TXT；检索“住宿报销”。选择「从知识库撰写」模板，为知识节点勾选刚创建的资料库，保留 Agent 为本地模式。执行输入“住宿报销标准”，可获得包含命中原文及来源标记的 DOCX。配置模型后，该节点可按提示词撰写与总结。

## 数据兼容

本版将 SQLite schema 从 v1 升级为 v2，保留已有项目、任务、配置和文件。新增流程、运行、资料库和索引记录。升级后不要再用旧版 EXE 打开同一数据库；备份请先退出程序再复制整个 `.opsbuddy` 目录。

## 0.7.0 运行结果与常用模板

工作流列表提供会议纪要、撰写审阅、表格汇总、资料到汇报、知识库撰写、条件分支六个模板。点击即打开节点画布；为知识库节点选择资料来源、确认 Agent 的模型和输出类型，再保存执行。

Agent 默认使用“对话问答”直接输出文字，可用于总结、分析和审阅；需要交付文件时选择 Word、PPT、Excel 等。上游文字会传递到下游，实际文件仍保留在项目中。

运行快照上方显示节点和连线，下方直接显示执行结果与文件内容预览。点击处理节点可查看其输出，右侧保留状态与运行历史；“返回编辑”回到当前流程定义，不修改历史快照。预览为内容提取，不是 Office 排版渲染。
