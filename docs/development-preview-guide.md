# 轻量开发与 Markdown（0.14.0）

只交付 Windows 桌面版，后端 Go；网页预览是桌面内的成果视图。

## 使用

1. 选择已配置模型，点击“制作网页”或“Markdown 文档”，也可直接要求“生成 HTML 计算器”或“整理成 MD 文档”。
2. 任务生成文件后自动展开右侧预览，也可点击成果文件重新打开；MD 显示标题、表格、列表、引用与代码块，HTML 可以点击交互。
3. 右侧切换“源码编辑”可修改内容，再切回“预览”查看效果；复制按钮复制完整源码。
4. “保存新版本”生成新文件并保留原文件。继续用自然语言修改时，点击当前成果底部的继续修改按钮，引用该版本。
5. 用“另存到本机”导出实际文件。会话正文也支持 Markdown，代码块可复制。

## 范围

- HTML 首批支持单文件、内联 CSS / JS；预览不加载外部网络依赖，没有桌面桥接。页面在独立沙箱中运行。
- MD 不执行原始 HTML，也不自动请求远程图片；链接可主动打开。
- 单文件最多 512 KB。HTML 需要完整 html 文档；空白、非法编码或不完整网页会报错，不能显示伪成功。
- 多文件项目现支持 Go / Node.js / Python 标准库项目；尚不自动安装第三方依赖、执行任意 shell 构建命令或承诺任意工程兼容。
- 模型请求使用当前明确选择的连接；生成不悄悄降级成本地模板。真实内容质量仍取决于配置的模型。

## 验证

Go 测试用模拟模型验证请求、真实文件写入、格式推断、继续修改及原文保留。Windows WebView2 自检覆盖 Markdown 渲染、源码编辑并保存新版本、HTML 按钮 2+3=5、父页面隔离与网络请求阻断。验证不调用付费模型，不等于所有第三方页面兼容性测试。

## 右侧栏

点击顶栏右侧图标或按 Ctrl+Shift+B 打开 / 关闭。选择会话或项目文件，可搜索、切换与隐藏列表。拖动左边界调整宽度，双击恢复默认；标题栏展开按钮提供大预览。下载位于标题工具栏，系统打开 / 所在位置位于底部更多菜单。


## 代码项目与后端

直接输入“帮我写个 2048，并本地启动”，会生成 HTML 文件并自动打开交互预览，不必先选网页格式。重新打开旧版已返回完整 HTML 的会话，也会从原始回复提取真实文件并展开预览；原始回复保留在折叠区，无需再请求模型。

需要后端时，可选择“代码项目（含后端）”，或明确要求“用 Go / Node.js / Python 开发一个服务并启动”。右侧提供：

- **预览**：服务实际就绪后加载网页；纯接口服务可在首页返回 JSON 服务说明。
- **项目文件**：选择并编辑项目内的真实文件，保存新版本，或保存并运行；旧版本与原始 ZIP 保留。
- **运行日志**：查看标准输出、错误输出、启动失败和命令行退出码。
- **本机运行 / 停止**：明确要求“启动/运行”时生成后自动启动；服务项目生成后或打开预览时自动启动；命令行脚本仍点击运行。停止后结束进程树和预览监听端口。

模型生成项目包含语言、入口、运行模式和文件列表，保存为真实源码目录，ZIP 仅在主动导出时生成；最多 40 个文件、源码合计 512 KB。服务从 PORT 环境变量读取随机端口，只监听 127.0.0.1；网页和接口由同一服务提供，资源及 fetch 使用 `./api` 等相对路径。项目使用本机已安装且加入 PATH 的 Go、Node.js 或 Python；当前不自动安装工具链或第三方依赖。Go 使用本机工具链且关闭模块网络下载。

运行会在本机以当前用户权限执行代码，属于真实程序执行。预览页面则使用独立本机来源、随机路径和隔离 iframe，没有桌面桥接，不能调用 OpsBuddy 的工作空间 API。页面预览隔离不等于操作系统级代码沙箱。运行时只传入必要的语言/系统环境变量，不把模型密钥传入子进程。

最多同时运行 3 个项目。关闭桌面应用会停止运行进程；重开后保留源码，未打开预览的项目不启动；主动打开服务项目预览时自动启动。每次运行在 `.opsbuddy/code-runs` 下创建新的工作目录，运行日志可查看其位置，源目录不会被运行时改写。

## Vue 与页面诊断

内置 Vue 3.5.44 的官方全局 / ESM 生产构建及 MIT 许可。常见 Vue CDN 地址会改为本地资源；新项目使用 __opsbuddy_runtime__ 路径，不需要联网下载 Vue 或安装 npm。仍不自动安装任意第三方依赖，不支持未经构建的 .vue 单文件组件。

项目文件视图提供源码文件树，打开源码目录后可用自己的编辑器修改，重新运行读取磁盘内容。服务启动成功与页面成功分开显示；脚本错误、资源加载失败和隔离策略阻断会显示在预览上方，可跳到源码或运行日志。新生成的 Vue 页面若只有加载占位而没有实际模板，会被拒绝保存并提示补齐。
