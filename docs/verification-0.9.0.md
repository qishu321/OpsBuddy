# 0.9.0 自动预览与前后端运行验证

2026-10-16，Windows 桌面版。

## 修复与能力

用户“帮我写个2048，并本地启动”在旧版被分成 chat，只显示代码。新版识别常见页面、游戏与服务/脚本开发意图，页面生成后交付真实 HTML 并自动打开已有右侧预览链路。完整 HTML 的旧聊天回复打开时可直接提取为文件，原文保留在折叠区，不增加模型请求。

多文件代码项目以包含运行清单及源码的 ZIP 保存。支持本机 Go、Node.js、Python 标准库项目，运行模式为 HTTP 服务或命令行。明确要求“启动/运行”时自动启动；右侧可查看实际预览、项目源文件、日志、退出码，保存新版本和停止运行。服务就绪后才提供预览 URL；失败显示真实错误。

Windows Job Object 负责进程树退出；每个服务有独立本机预览代理、随机路径和隔离 iframe。桌面主界面的 frame-src 策略补充允许 127.0.0.1 回环项目页面；原来的单文件预览仍禁用外部网络与桌面桥接。桌面 API 保持进程内访问。
