# OpsBuddy v0.18.0 — Windows & Linux preview

## 中文

- 新增真正的 Linux 桌面入口、GTK3 / WebKit2GTK 4.1 构建、原生文件对话框与默认应用打开。
- Windows 与 Linux 共用 Go 后端、React 界面、项目、办公文件、工作流、知识库和多 Agent 编排。
- Linux 支持 AES-256-GCM 本地凭据加密；密钥存放于用户配置目录独立0600文件。Windows 保持 DPAPI。
- 新增中英文 README、双平台 GitHub Actions 测试/构建、按 tag 发布及 SHA-256 校验。
- 清理版本库中的本机运行目录和测试二进制，保留演示源码与可导入示例。

Windows：下载 EXE 或 ZIP，需要 WebView2。Linux：下载 tar.gz，Ubuntu 24.04兼容的 x64图形桌面，需要 GTK3、WebKit2GTK 4.1和 xdg-utils。Linux 暂无原生桌宠；macOS、ARM64和 AppImage 不在本次范围。该版本为未签名的开发预览版。

升级前正常退出旧窗口。Windows 保留 EXE 旁 `.opsbuddy`；Linux 默认读取用户配置目录。跨平台迁移需要重新配置模型 API Key。运行生成的代码仍需要对应本机语言环境；导入项目不会自动执行源码。

## English

- Adds a real Linux desktop entry point, GTK3 / WebKit2GTK 4.1 build, native dialogs and default-application opening.
- Shares the Go backend and React UI across Windows and Linux, including office tools, projects, workflows, knowledge and multi-agent orchestration.
- Adds Linux local credential encryption with AES-256-GCM and a separate 0600 per-user key file; Windows keeps DPAPI.
- Adds bilingual READMEs, platform CI builds, tagged prereleases and SHA-256 checksums.
- Excludes local execution directories and test binaries from the source tree, retaining demo source and an importable sample.

Windows requires WebView2. Linux targets Ubuntu 24.04-compatible x64 graphical desktops with GTK3, WebKit2GTK 4.1 and xdg-utils. The pet remains Windows-only. macOS, ARM64 and AppImage are not included. This is an unsigned development preview.

Close the old version before upgrading. Preserve Windows `.opsbuddy` data beside the executable; Linux defaults to the user configuration directory. Re-enter model API Keys when migrating across operating systems. Generated code requires the corresponding local toolchain; importing a project never runs it automatically.
