# 桌面小搭子

0.15.1 Windows 桌面版内置原创像素小猫。参考 Familiar 的任务反馈思路，以及用户提供的 Codex 宠物截图和 [官方 Pets 文档](https://learn.chatgpt.com/docs/pets?surface=app) 中的浮动入口、状态反馈及动画开关。小猫和 Go 原生实现属于 OpsBuddy，不复制其他应用的素材或运行依赖。

## 使用

- 单击小猫摸摸，悬停会探头并在窗口内朝鼠标方向看，拖动挪位置，松开后保存；双击返回工作台。
- 常态不显示操作条；鼠标靠近小猫时，下方出现聊天、暂停/播放图标，分别返回 OpsBuddy 和切换动画。离开后短暂延迟收起，便于移入操作条。右键仍可置顶、隐藏或打开工作台。
- 在“设置 → 工作空间 → 桌面小搭子”也可控制显示、活跃模式和置顶。
- 气泡恢复紧凑比例，使用柔和圆角、绿色小标题和一行深色提示。标题为 14 px、正文为 16 px，均使用灰阶抗锯齿。125% 显示缩放时正文为 20 物理像素；150% 为 24 像素。切换 DPI 时重建原生字体和像素缓冲区，文字不通过放大位图处理。
- 活跃模式下，空闲也会有呼吸起伏、眨眼、摆尾、左右探头、挥爪与伸懒腰；不会自行在桌面上游走。
- 工作时显示读取、思考、写代码、生成文件、启动预览、检索与多 Agent 协作等阶段；摸摸和拖动反馈结束后恢复实际任务状态。
- 完成、失败等气泡约三秒收起。鼠标交互会重新显示提示，没有声音、不主动抢走输入焦点。

## 轻量策略

- 与主程序共用 Go 进程，以 Win32 透明窗口绘制，不新增 WebView、浏览器进程、后台服务或模型请求。
- 静待时约 2 帧/秒，工作与交互短动画约 6 帧/秒。暂停动画后保留静态姿态，气泡收起后停止定时器和持续重绘。
- 只处理桌宠窗口内的鼠标消息，不监控全局鼠标、不截屏、不轮询任务接口。状态通过容量为一的本机事件通道推送。
- 复用 288×278 逻辑像素画布；原生显示缓冲区按屏幕 DPI 分配。100% 缩放时单个缓冲区为 320,256 字节，125% 时为 501,120 字节；这不是整体内存占用。
- 隐藏后销毁窗口、字体和绘图缓冲区并退出消息循环；主程序退出时桌宠同步退出。设置、位置仍保存在数据目录的 pet.json。
