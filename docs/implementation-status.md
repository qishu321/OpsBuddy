## 技术决策

- 按用户要求采用 **Go 后端**；文件解析、生成、任务与配置均由 Go 实现，无 Python 后端。
- 桌面发行版采用 Wails v2.12.0 + Go + React/TypeScript。界面和 Go 代码嵌入同一 Windows EXE，使用系统 WebView2 承载界面，提供独立窗口。
- 桌面运行不启动浏览器、不监听本地 TCP 端口、不启动独立服务；保留标准库 HTTP Handler 作为进程内请求分发层。旧浏览器服务入口已停用。
- 原生文件选择、另存为、默认程序打开、Explorer 定位、窗口缩放/最小化/最大化、单实例及关闭收尾已接入。当前提供便携 EXE / ZIP；未制作安装向导与代码签名。
- 使用 Excelize 处理 XLSX，pdfcpu 处理 PDF 页操作，rsc.io/pdf 提取文本；DOCX/PPTX 由 Go 生成标准 Open XML 包。
- 配置与任务存储在本地 SQLite（modernc.org/sqlite v1.58.0，纯 Go），模型 Key 仍使用 Windows DPAPI；单用户单进程。实体按 kind/ID 分行保存 JSON payload，只写入变更记录，事务提交；尚未拆分为完整关系模型或分页查询。
- 本地执行仅操作上传副本与应用成果目录，不开放任意磁盘目录或任意命令执行。

## 关键限制

1. 对话任务直接呈现模型文本；办公任务经过 JSON 结构解析后由本地固定工具生成文件。目前不是任意调用工具的通用 Agent。
2. Word 正文局部修改只替换选定段落文字，表格不修改；PPT/Excel 仍读取内容并重新生成，不能保证原排版不变。
3. 本地模式仅整理内容或执行已实现规则。它不能代替模型做语义推理。
4. Office 结构和可读性检查已实现，未接入 Office/WPS/LibreOffice 逐页渲染验证。
5. 普通任务不自动重试；协作节点最多自动重试一次、审阅返工最多两轮，会产生额外真实模型请求。取消本地请求不能保证供应商停止计费；无完整 token/成本统计。
6. OpsBuddy 桌面 API 在进程内处理。代码项目运行时按需启动独立本机服务及预览代理，退出/停止后关闭；不提供 OpsBuddy 独立网页版。
7. 配置快照保证已提交任务使用提交时配置，不代表历史模型/密钥可重放或输出确定性复现。旧任务不补造快照；当前重试入口仅加载原需求，用当前配置创建新任务。
8. SQLite 升级前必须停止旧 JSON 版服务；旧版不能识别新数据库锁。迁移保留旧 JSON、资产 ID/路径、DPAPI 密文和成果文件，数据库成功初始化后不再重复导入 JSON。此次仅在隔离合成数据目录验证，真实 `.opsbuddy` 未迁移。
