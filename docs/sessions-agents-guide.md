# 会话与子 Agent 使用指南

版本：Windows 桌面 0.4.0。

## 引用材料

输入框左侧 + 可以添加本机文件、引用整个材料文件夹，或勾选项目已有文件、Skill、声明式插件技能包。材料复制到工作空间，原文件保留。文件夹最多 16 个普通文件、合计 32 MB，不跟随目录链接；来源名称保留相对层级。

PNG/JPEG 可以拖入输入框并在文件面板预览。理解图片需选择支持视觉输入的模型并允许发送，最多 4 张、单张 8 MB / 2000 万像素。本地整理模式不能识图。

## 查看与继续修改

左侧切换「会话 / 文件」，文件面板列出当前项目的材料与成果。Office 是内容预览，使用系统应用打开可查看排版。任务中的「工具过程」可展开阅读真实步骤。

完成后直接在输入框补充要求。新一轮会关联当前会话、读取上一轮成果及最近历史摘要。Word 正文局部修改只替换选定段落文字，保留表格与其他文件内容；不支持新增段落、表格修改或复杂排版。PPT/Excel 的继续修改仍为重新生成。

## 派发子任务

点击「派发子任务」，填写主目标并编辑成员要求。默认 explorer 探查引用材料、researcher 依据材料分析、worker 制作成果，三者并行；reviewer 等其他成员完成后审阅，最后主任务综合实际交付生成最终文件。

每组 1–6 位成员，全局最多 3 个任务同时执行。每位成员的提示词、任务记录和轮次独立；只有审阅与主汇总按流程接收其他成员成果。当前没有联网检索、任意目录操作或模型自主无限组队。

运行阶段可给单成员追加指令。追加内容排入其下一轮，以本成员的上轮结果继续；不会修改已发出的模型请求。每成员最多追加 7 次，开始主汇总后不再追加，可在主会话继续提出新要求。整组停止会取消排队/运行请求，已有交付保留；关闭桌面后标记中断，不自动重复调用模型。

## Skills 与工作方式

独立专家库已合并到 Skills。输入框 + 可引用 Skill；未选择时自动匹配内置技能，不增加模型选择请求。原自定义专家会迁移为可编辑 Skill，显式引用时读取指导并保留原关联。其他自定义 Skill/插件先向模型提供名称与说明，再按需读取；每轮正文总额度为 4 项，使用内容/版本快照。项目说明与记忆保存背景和偏好，多 Agent 保留任务分工。

## 后续阶段

定时任务与记忆已提供；网站应用台、飞书/钉钉和语音会议仍待开发，详见当前实现状态。

## 视觉协议参考

请求适配参考 [OpenAI Images and vision](https://developers.openai.com/api/docs/guides/images-vision)、[Claude Vision](https://platform.claude.com/docs/en/build-with-claude/vision)、[Gemini Image understanding](https://ai.google.dev/gemini-api/docs/image-understanding)。接口结构测试不代表所配置模型一定具备视觉能力，真实供应商需用用户选择的模型验证。
