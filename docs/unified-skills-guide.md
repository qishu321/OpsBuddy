# 统一工作方式（0.11.0）

不再提供独立专家库，也不需要在输入框里选择角色。

- **Skills**：在扩展中管理工作方法，在输入框 + 中显式引用；不选则按任务自动匹配内置项。
- **项目说明与偏好**：项目卡片右下角编辑按钮，填写背景、目标、表达偏好和约束；新任务读取当前项目说明，提交后固定快照。当前要求优先。
- **记忆**：设置 → 记忆，保存跨任务的个人或项目偏好与经验，按相关性读取，可编辑或停用。
- **多 Agent**：保留检索、研究、执行、审查等成员分工，独立上下文与汇总流程保持原有方式。

## 旧自定义配置

升级时为每个原自定义专家创建一个可编辑 Skill，保留名称、说明、工作要求及关联技能、知识库。可在扩展 → Skills 搜索原名称，看到“已迁移”标记，修改或停用。

这些配置不会自动变成个人或项目记忆，避免把不同工作方式混到所有任务。显式选择迁移 Skill 时读取其正文，关联技能继续按需选取，知识库按当前项目边界检索。

旧专家记录作为兼容 ID 保留，不提供重复管理入口；已有工作流或定时计划仍可执行，将引用对应的迁移 Skill。编辑节点/计划的 Skills 选择后，改用统一技能配置。历史任务与已创建运行快照保留提交时的指导，不追溯改写。

迁移 Skill 可以删除，重启不会重新创建。若旧工作流或计划仍引用已删除项，运行会明确报错，需要在 Skills 选择中移除该项或选择其他技能。仅停用会保留记录，并停止读取该项及其关联内容。

内置基础角色 ID 在执行器内部保留用于旧配置兼容；它们不是新的用户入口，也不影响 Skills 的按需选择。
