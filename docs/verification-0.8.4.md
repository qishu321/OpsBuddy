# 0.8.4 轻量工作台与交互整理

2026-10-15，Windows 桌面版。

## 改动

- 首页统一 PPT、Word、Excel、PDF、HTML 和 Markdown 六个场景；文件整理保留为次要入口。删除重复的专家库、工作流首页跳转。
- 导航分为工作空间（工作台、项目、知识库）和工具（专家库、工作流、定时任务、扩展），保留全部功能入口与会话/文件切换。
- 缩短欢迎文案，统一卡片间距、字号和选中状态。小窗口采用紧凑布局，明暗主题沿用现有设计变量。
- 选择指定文件格式后，在输入框明确展示输出格式，支持恢复自动选择；清除时同时恢复通用角色，不改写输入内容。
- 已有模型时隐藏接入引导；未配置模型时一键打开添加表单。
- 版本信息保留在设置页；顶部保留项目、提醒及右侧栏开关。底部连接状态改为用户可理解的“已就绪”。
- 成功任务保留状态徽标与实际结果，删除重复的“任务已完成”标题；异常、运行中和停止状态仍有说明。
- 文件另存统一在预览顶部；更多菜单保留系统打开和文件位置。输入框底部显示发送快捷键。
- 沿用 0.8.3 截图粘贴、缩略图和图片独立发送能力。

## 验证

- TypeScript/Vite 构建、Prettier 检查、Go 桌面编译通过。
- 最终 EXE 在隔离目录运行 WebView2 集成检查，普通窗口与 880×600 窗口均 passed=true。
- 六个首页场景实际点击后匹配对应格式；一键恢复自动格式通过；配置模型后首页引导消失。
- 回归覆盖截图 paste 事件、缩略图解码/打开/移除、图文保留、只发图片按钮可用、拖入图片、会话删除保留文件、HTML 交互与源码保存、Markdown、右侧栏开关/搜索/宽度、工作流画布/执行快照、知识库、子任务、定时提醒与记忆。
- 普通窗口无附件输入框高 159px，小窗口约 157px；HTML 预览占右侧面板高度约 77% / 69%。
- 结果：`.cache/smoke-polish-084/smoke-result.json` 与 `.cache/smoke-polish-084-small/smoke-result.json`。

本轮检查为桌面 WebView2 自动化交互与 DOM 布局检查，没有执行系统截图工具到 Ctrl+V 的物理键盘测试，也没有向真实模型发送付费请求。未修改业务后端逻辑，Go 全量测试与 vet 沿用 0.8.3 已通过的结果；本轮重新编译桌面后端并执行集成回归。
