# 0.8.1 天气与 HTML 预览修复

2026-10-15。

## 问题与修复

- 旧 HTML 类型和历史成果影响普通天气提问。现在“上海天气”走直接回答，明确要求网页才生成网页。
- 原先只有模型文本请求，没有天气数据工具。现在 Go 先解析城市、查询 Open-Meteo，再将带数据时间、来源及单位的结果交给所选模型。只发送城市/坐标到天气服务，不发送模型凭据或会话材料。
- 连接失败、无城市、空值、过期数据、HTTP 错误不能转成模拟天气或成功成果。
- HTML 返回中混入说明与代码围栏。新成果只提取完整 html 文档，旧成果预览也兼容清理；原始文件保留。
- 成果面板可以展开，便于查看网页。

## 验证

- Go 测试：旧 HTML 类型/父会话不影响直接天气回答、明确网页需求仍保留、工具数据进入所选模型请求、离线无虚假成功、接口错误/空值/过期/取消处理、带说明的 HTML 提取。
- 实际 Go 联网查询上海通过：2026-10-15 16:30 Asia/Shanghai，阴，22.1°C，体感 21.9°C；今日 17.3–24.2°C。这是 Open-Meteo 天气模型估算，不冒充气象站实测。
- 已使用现有唯一模型连接 deepseek-flash 实际执行一次上海天气任务，完整链路通过，结果保存在会话 99c6533f6866d9aa137d548b；另有模拟服务覆盖失败与路由回归。
- 单城市、当前及未来 7 天已接入；尚未实现通用网页搜索、任意工具循环及多城市汇总。没有为此开放 HTML 沙箱网络。

接口说明：[天气](https://open-meteo.com/en/docs)、[城市查询](https://open-meteo.com/en/docs/geocoding-api)。

- 最终桌面包 WebView2 自检 passed=true：旧 HTML 页面外说明被剔除，预览展开通过，MD / 网页交互和已有工作流、知识库、会话、定时等检查通过。
