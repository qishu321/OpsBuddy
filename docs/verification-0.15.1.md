# 0.15.1 宠物视觉修正

日期：2026-10-16，Windows amd64。

用户反馈 0.15.0 的提示气泡、文字和常驻按钮过于抢眼。本次恢复接近旧版的比例；保留低帧率动作和 DPI 适配。

- 逻辑画布 288×278，小猫重新采用旧版位置与比例，气泡缩为 260×66。
- 气泡使用抗锯齿圆角和轻阴影，14 px 绿色标题、16 px 深色单行提示，避免多行操作说明占据视觉主体。
- Win32 字体质量从 NONANTIALIASED 改为 ANTIALIASED，保留逐 DPI 创建字体。本机 125% 缩放时正文为 20 物理像素。
- 底部不再常驻“打开/静止”大按钮。悬停显示两个小图标，离开后延迟收起；隐形操作条不接受点击。
- 待机小动作约 2 帧/秒、工作/交互约 6 帧/秒；关闭动画后仍停止定时器。

## 验证

`scripts/test.ps1` 通过全部 Go 测试、Go vet、TypeScript 与 Vite 构建；`npm run format:check` 通过。

原生生命周期测试通过：平滑文字实际绘制、96/144/192 DPI 消息重建、悬停前隐藏和悬停后出现、打开/恢复动画图标、单击摸摸、双击、拖动位置保存、重复开关释放。像素测试验证默认操作条透明、悬停操作条可见、气泡边缘有覆盖率过渡。

本机独立原生测试进程短测：活跃待机 3 秒重绘 6 次；关闭动画后采样约 3 秒，重绘 0 次。两段 CPU 时间增量均为计时精度下的 0，不能理解为动画完全不消耗 CPU。私有内存从 49,745,920 增至 54,480,896 字节，增量约 4.52 MiB，包含 Go/GDI 初始化，不是整个 OpsBuddy 的固定占用。

证据：`.cache/pet-native-0151-report.json`、真实原生绘制缓冲区 `.cache/pet-native-0151-preview.png`。`.cache/pet-hover-0151.png` 为同一代码的悬停图标演示。导出预览已正确把半透明边缘合成到浅色背景，避免预览器把阴影显示成深色轮廓。

用户数据、模型和宠物位置保留；替换前正常关闭旧实例，备份为 `state-before-0.15.1-*.db`。交付仍为 `release/OpsBuddy/OpsBuddy.exe`，版本 0.15.1。
最终 EXE 集成检查通过：.cache/smoke-pet-0151/smoke-result.json，passed=true。包括办公文档、工作流、知识库、源码项目与离线 Vue、项目会话边界、截图、定时任务、记忆、子 Agent、宠物设置和持续待机；125% 下正文 20 像素，非悬停时操作条不可见。
