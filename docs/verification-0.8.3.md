# 0.8.3 截图粘贴

2026-10-15，Windows 桌面。

- 输入区域处理 paste 事件的图片项/文件列表，截图按 Clipboard_Screenshot 名称保存为真实附件。
- PNG / JPEG 保留原图；其他浏览器可解码图片转换为 PNG。限制每轮 4 张、单张 8 MB、2000 万像素。
- 缩略图支持点击打开右侧图片预览、移除附件。图片拖入和文件选择继续沿用原链路。
- 文本粘贴保持编辑器原生行为；图片同时带有纯文字时，在输入光标处保留文字。
- 只添加图片也允许发送，使用明确的默认识图提问并走直接对话，避免继承旧 HTML 格式。识图仍需所选模型支持图片输入。
- 本次不读取系统剪贴板后台内容，不调用剪贴板轮询或要求额外读取授权。仅处理用户主动触发的粘贴事件。

## 验证

TypeScript / Vite 构建、Go 全量测试与 vet、格式检查通过。
桌面 WebView2 内使用 ClipboardEvent + 真实 PNG 二进制验证：粘贴上传、缩略图解码、图文一起粘贴、点击预览、移除、纯文字粘贴不被拦截；普通和 880×600 窗口均通过。另验证图片无文字时发送按钮可用，未实际发送付费模型请求。
已有测试覆盖 PNG 图片进入 OpenAI-compatible / Anthropic / Gemini 请求载荷。

本轮验证使用应用内粘贴事件，没有替换用户系统剪贴板，也没有执行 Windows 截图工具的端到端键盘操作；不声称已验证全部第三方截图软件。
