# 项目与会话

适用于 0.12.0 Windows 桌面版。

- 左侧「会话」按项目分组。点击项目名称切换，点击箭头折叠或展开；名称旁数字是该项目的会话数。
- 项目行的 `+` 在该项目内新建会话；左上角「新建任务」使用当前项目。输入框下方与顶部项目选择器显示当前归属。
- 点击任何会话会切换到它所属的项目。继续追问沿用该会话的历史；新建会话不自动继承同项目其他会话的内容。
- 搜索匹配项目名或会话标题，结果仍显示在项目名下。左侧「文件」和右侧预览列表仅列出当前项目的文件。
- 切换项目会清空未发送草稿、附件、知识库引用、技能选择和当前预览。尚未完成的任务继续在原项目运行；返回原项目即可查看。上传中切换项目，文件仍保存于原项目，不会附到新项目的输入框。

模型任务只带入明确引用的同项目历史与材料，以及该项目的说明、相关项目记忆。个人偏好是用户主动保存的全局设置，仍可跨项目使用；可在「设置 → 记忆」查看、停用或选择项目范围。Skills 与模型连接属于全局工具配置，不等同于共享会话历史。

已有会话按照已保存的项目归属显示，不根据标题猜测或自动重新分配。删除某个项目下的会话不会删除其他项目的会话，项目文件仍保留。
