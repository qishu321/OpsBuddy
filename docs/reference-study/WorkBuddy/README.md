上述是结构观察，未核实每个入口的后台实现；不复制专家市场的营销承诺、名称库和腾讯专属服务。

## 开发清单

1. 首页常用任务：文档、PPT、表格、PDF、文件整理、会议纪要；展示具体输入/输出和已实现限制。
2. 专家卡片：用途、适用输入、输出形式、模型/技能/工具要求；“使用”只填入当前会话配置，不立即执行。
3. 资料入口：文件、知识库、目录分开；来源清晰可移除，不把未引用的目录自动发给模型。
4. 输入快捷方式：@ 选择明确上下文，/ 选择 Skill 或命令；依赖未安装时说明缺失，不假装已执行。
5. 真正的 Agent 循环、MCP 调用、插件生命周期继续按 OpenClaw / DSH 的调研计划补齐，见 [统一参考目录](../OpenClaw-DSH/README.md)。

## 只保留桌面版

OpsBuddy 保持 Go + Wails，窗口内嵌界面，运行不需独立浏览器服务。删除 npm 的 server/preview 入口；dev 改为桌面重建启动。旧 go run ./cmd/opsbuddy 仅提示桌面启动方式并失败退出，不监听 TCP。前端编译器用于生成 EXE 内嵌资源，继续保留。

本次参考文档不等于上述功能全部交付；当前版本变更只收拢桌面启动入口。后续实际新增能力须单独实现并验收。
