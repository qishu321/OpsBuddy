# 16 AI 视频生成

## 目标与阶段

P2 支持文生视频、图生视频及分镜生成短片，重点做好异步任务、素材管理和与剪辑衔接。不以自研视频基础模型为范围。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| VID-01 | P2 | 支持文本、参考图、可选首尾帧输入；可用输入形式按供应商能力过滤 |
| VID-02 | P2 | 配置比例、时长、分辨率和模型；展示支持范围、估价及是否包含音轨 |
| VID-03 | P2 | 将长需求拆成分镜脚本，支持修改镜头描述、顺序和时长后批量生成 |
| VID-04 | P2 | 保存外部任务 ID，展示排队/生成/成功/失败状态，后台轮询与重启恢复 |
| VID-05 | P2 | 支持取消请求、失败镜头重试和保留成功镜头；不能取消的远端任务明确提示 |
| VID-06 | P2 | 下载结果到成果目录，校验媒体可读性、时长与分辨率，支持预览及送入剪辑 |
| VID-07 | P2 | 记录每个镜头的输入、模型、生成参数、费用和来源，支持局部重做 |

## 异步作业规则

提交前保存本地作业和幂等标识；提交成功后关联远端 ID。提交超时进入“状态待核对”，优先查询已有作业，无法确认时由用户决定是否重新提交。禁止自动无限重发付费请求。

轮询采用有上限的间隔退避；用户关闭页面不会丢失作业。应用重启后检查未终结作业；只有下载并验证成功才将成果标为可用，远端成功但下载失败应显示“生成完成，保存失败”。

取消是尽力操作；无法取消时停止本地后续编排，但保留远端跟踪和费用说明。单镜头失败不要求重生成所有成功镜头。

## 质量边界

短片实际时长、人物一致性、文字和动作准确性受生成能力限制，界面显示实际结果。精确转场、配音、字幕、音乐与总时长由剪辑阶段处理。生成视频不是精确剪辑的替代。

## 验收

创建包含 3 个镜头的任务，成功镜头可播放；模拟应用重启后继续追踪同一批远端任务，无重复提交。失败一个镜头时可只重做该镜头。临时链接过期显示真实错误并尝试合法重新取回，不能展示虚假下载成功。

依赖：媒体供应商、异步队列、成果下载、预算、AI 剪辑模块。
