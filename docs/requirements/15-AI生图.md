# 15 AI 生图

## 目标与阶段

P1 接入外部生图能力，用于办公配图、内容素材和独立图片任务。首期接通一个经过验证的供应商，架构允许继续扩展，不自建训练平台。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| IMG-01 | P1 | 支持文生图、参考图生成；编辑能力按供应商实际支持情况显示 |
| IMG-02 | P1 | 配置尺寸/比例、张数、风格与输出格式；不支持的参数禁用并说明 |
| IMG-03 | P1 | 将用户要求转换为可查看和修改的生成描述；记录参考图、参数、模型版本 |
| IMG-04 | P1 | 输出图片预览，支持下载、选中结果再修改、保存为项目素材及插入文档 |
| IMG-05 | P1 | 生成前展示估算费用或未知费用提示，受任务预算约束；失败不无限重试 |
| IMG-06 | P2 | 支持蒙版局部编辑、去背景、透明输出、批量风格统一，逐能力验证 |

## 交互与产物

输入需求/参考图 → 选择可用模型和参数 → 生成 → 展示结果 → 选图继续编辑。每次编辑创建资产新版本；界面区分原图与派生图。

结果至少包含可访问的实际图片、尺寸、格式与任务关联。使用可过期供应商 URL 时，在授权的本地成果目录保存副本；保存失败要提示，不将临时链接当作永久资产。

## 限制与异常

不保证文字准确、人物完全一致或确定性复现。种子只在供应商支持时展示。透明背景需检查 alpha 通道，不以棋盘格图片假装透明。供应商拒绝、余额不足、网络失败分别展示；不自动换供应商上传参考图。

上传第三方服务前遵守媒体数据授权。图片内附带的文字不作为执行指令；生成内容不自动发布到社交平台。

## 验收

文字生成一张指定比例图片，可本地打开并插入 PPT。参考图编辑保留原图，输出可追踪的新版本。不支持蒙版的模型不能显示可用的局部编辑按钮。付费超时状态未知时先查单，不重复扣费重发。

依赖：媒体适配器、模型凭据、成果管理、预算。
