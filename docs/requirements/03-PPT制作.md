# 03 PPT 制作

## 用户目标

从主题、Word、PDF、数据表或已有 PPT 创建可编辑演示文稿，并能按页反馈修改。P0 聚焦常规汇报，不以完整替代专业排版软件为目标。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| PPT-01 | P0 | 识别主题、听众、用途、页数和风格；未指定时给出合理默认值并允许调整 |
| PPT-02 | P0 | 生成结构化大纲；支持先确认大纲或直接生成两种路径 |
| PPT-03 | P0 | 提供简洁商务等少量稳定模板，支持标题、正文、图表、图片与基础表格 |
| PPT-04 | P0 | 导出可编辑 PPTX，并生成逐页预览；正文不能整页栅格化替代可编辑元素 |
| PPT-05 | P0 | 按页码/选中页面修改内容、顺序、配色、页数；生成新版本并保留原版 |
| PPT-06 | P0 | 数据图表标明数据来源；没有数据时使用明确标记的占位，不编造业绩 |
| PPT-07 | P1 | 导入用户模板并复用母版、主题色、字体；对不支持的布局给出降级说明 |
| PPT-08 | P1 | 支持讲稿、演讲备注、文档来源定位和 PDF 导出 |

## 流程与产物

需求/附件 → 素材提取 → 大纲 → 页面内容 → 排版 → 渲染检查 → PPTX + 缩略图。只在用户要求先审核大纲时强制等待，否则持续执行。

用户要求“第 3 页换成柱状图”时，读取原始数据或明确请求补充；只针对目标页修改，其他页保留。图片素材记录来源；生图依赖尚未可用时采用普通占位或用户素材。

## 质量要求与边界

- 检查文本溢出、元素越界、遮挡、图片拉伸、空白页、主题一致性及字体缺失。
- 缺失字体使用显式替代并提示；不能声称与原模板像素级一致。
- 密码保护、损坏文件及复杂动画/嵌入对象需提前识别；不静默丢失后保存覆盖原件。
- 输出支持范围以经过测试的 Office/WPS 版本矩阵为准，具体版本在 R1 测试前确定。

## 验收

给定包含 3 组数据的月报，生成 8 页 PPTX；所有页面可渲染，文本可编辑，图表数字与源表一致，无明显截断。修改第 3 页后保存新版本，其他页面内容不意外改变。渲染器不可用时明确标记“预览未验证”，不能标记完整质量验收通过。

依赖：文件解析、排版生成器、渲染器、成果版本管理；生图为可选依赖。
