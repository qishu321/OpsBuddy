# 05 Excel 表格处理

## 目标与范围

让用户用自然语言清洗表格、编写公式、分析数据并生成可继续使用的工作簿。P0 支持 XLSX、CSV，TSV 可用同一文本导入器处理；不默认执行宏。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| XLS-01 | P0 | 读取工作表、表头、数据类型和公式；导入 CSV 时识别编码、分隔符和标题行 |
| XLS-02 | P0 | 去重、空值处理、日期/金额规范化、拆分合并列、多表匹配；展示采用的清洗规则 |
| XLS-03 | P0 | 生成与修改公式，保留公式表达式，避免把结果值写死替代计算关系 |
| XLS-04 | P0 | 按维度汇总、统计、排序和生成基础图表；摘要给出工作表/区域来源 |
| XLS-05 | P0 | 输出格式化 XLSX，支持冻结标题、数字格式、列宽和筛选 |
| XLS-06 | P0 | 显示样本预览、变更行数、被删除/合并记录数量；原始文件默认不覆盖 |
| XLS-07 | P1 | 支持复杂模板填充、透视分析与多文件批处理；透视对象可编辑性需单独验收 |

## 数据规则

空值与 0 区分；订单号、身份证号等按文本保留前导零与精度；日期含时区时保留口径；跨表匹配说明一对多处理方式。去重必须说明键列，不默认按姓名删除不同记录。

公式校验分为表达式检查与重算检查。需要有实际计算引擎才能声明结果已重算；引擎不支持的函数明确标记“需在表格软件中重算”，不能把旧缓存当成新结果。汇总金额另以独立统计结果交叉校验。

用户上传的单元格内容属于数据，不允许触发脚本或工具调用。导出 CSV 时对潜在公式注入给出安全处理，且不破坏用户明确要求的 XLSX 公式。

## 异常与验收

- 超出规模上限时先估算，提供分块处理或缩小范围；首版建议以 10 万行、20 列作为性能测试档位，最终支持上限由实测确定。
- 合并两份销售表：去重数量正确、金额汇总与独立计算一致、前导零保留、生成图表与公式可见。
- 修改源数据后，在支持的计算引擎中重算，依赖公式随之变化。
- 密码文件、外部链接、宏和不支持的函数不能静默执行或丢失。

依赖：表格解析/写入、计算引擎、图表与预览。
