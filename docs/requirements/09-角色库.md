# 09 角色库

## 概念

角色是可复用的行为与能力配置；Agent 是任务执行中的运行实例。选择“PPT 助手”只建立配置，不代表启动一个持续后台工作的数字员工。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| ROLE-01 | P0 | 内置通用办公、PPT、文档、表格、PDF、文件整理角色；媒体角色随能力发布 |
| ROLE-02 | P0 | 卡片展示名称、用途、默认模型及已启用工具/技能数，支持搜索和分类 |
| ROLE-03 | P0 | 创建、复制、编辑、启停、删除个人角色；内置模板通过复制修改 |
| ROLE-04 | P0 | 配置目标说明、提示词、默认模型、Skills、MCP/插件工具白名单、输出风格 |
| ROLE-05 | P0 | 保存前校验依赖及模型能力；缺失工具时展示具体缺项和解决入口 |
| ROLE-06 | P0 | 角色变更产生版本；已启动任务继续使用原配置快照 |
| ROLE-07 | P1 | 导入/导出角色配置，不含密钥和个人绝对路径；支持组合协作模板 |

## 权限与优先级

角色仅声明需要哪些工具，不能自行授予目录、网络或执行权限。有效权限取系统限制、用户授权、项目范围与角色工具白名单的交集。

用户当前指令高于角色的默认风格和任务建议；系统安全边界不能被角色提示词覆盖。角色附带资料只在明确选用时加载，不自动注入所有项目历史。

## 验收

复制 PPT 角色，选择新模型并启用一个技能，新任务使用该配置；旧任务配置不变化。删除所依赖技能后，角色显示失效依赖；运行时不能假装技能可用。导出配置中无 API Key。

依赖：模型配置、技能/工具注册、权限。
