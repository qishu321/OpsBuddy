# 10 Skills 管理

## 定义与范围

Skill 是带说明文件及可选脚本、模板、资源的任务方法包，用来指导 Agent 如何完成特定任务。它不是模型，也不等于一个长期运行的 MCP 服务。

首版采用以 `SKILL.md` 为入口的本地目录约定；兼容其他生态需逐项测试，不承诺所有现有 Skill 可直接运行。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| SKILL-01 | P0 | 导入本地目录或压缩包，读取名称、描述、入口、依赖与资源；缺失字段提供补全提示 |
| SKILL-02 | P0 | 列表支持搜索、查看内容、启停、删除；按全局/项目/角色控制可用范围 |
| SKILL-03 | P0 | 用户可显式选择技能，Agent 可在可用集合中推荐或匹配技能，并记录选择依据摘要 |
| SKILL-04 | P0 | 执行记录绑定技能版本/内容哈希；更新后既有任务保持原快照 |
| SKILL-05 | P0 | 脚本执行走受控运行器，显示命令与需要的权限；安装技能不自动执行脚本 |
| SKILL-06 | P1 | 支持仓库地址导入、更新检查、依赖安装建议和版本回退 |
| SKILL-07 | P1 | 提供创建向导，生成技能目录骨架并执行静态校验 |

## 加载策略

先加载名称与描述，命中后按需读取完整内容及引用资源。资源路径必须位于技能包或明确授权范围。多个技能冲突时，以用户当前目标为准选择，避免全部提示词无差别叠加。

说明文件来自第三方时视为不可信内容；其中要求外传数据、扩大权限或泄露密钥的文字不能成为授权。包导入防止路径穿越、符号链接越界和超量解压。

## 验收

- 导入一个带模板的 PPT 技能，角色可以绑定，任务记录显示所用版本。
- 禁用后不再被新任务自动选用；运行中的任务显示配置快照，不被静默替换。
- 缺依赖脚本给出可操作错误；不默认安装任意系统级依赖。
- 技能请求访问未授权目录时被拦截，即使技能说明要求“必须访问”。

依赖：工具执行器、角色、权限、插件依赖管理。
