# 29 统一 Agent 运行与工具执行

状态：待开发，2026-10-15 依据 OpenClaw / DeepSeek Harness 调研补充。补充第 02、11、12、14、23 章，不覆盖既有已实现功能。[调研与实施计划](../reference-study/OpenClaw-DSH/README.md)。

| 编号 | 优先级 | 需求与验收 |
| --- | --- | --- |
| LOOP-01 | P0 | 同一 Go 运行接口处理普通任务、子 Agent、工作流节点与定时任务，保存实际模型配置与任务边界 |
| LOOP-02 | P0 | 支持模型提出工具调用、执行真实工具、将结果回灌并继续；有次数、时间、输出额度上限 |
| LOOP-03 | P0 | 工具具有唯一名称、JSON 参数结构、执行器、状态、结果与产物引用；未知名称或非法参数不得执行 |
| LOOP-04 | P0 | 首批复用现有文件、知识库与办公工具；生成成功需真实文件和相应格式检查 |
| LOOP-05 | P0 | 任务、模型请求、工具开始/结束、取消和产物分别持久记录；密钥和私有思维链不进入可见轨迹 |
| LOOP-06 | P0 | 无模型或工具能力未通过测试时明确拒绝相应任务，不退回固定排版并冒充模型执行 |
| LOOP-07 | P0 | MCP 连接、发现、实际调用分开验收；远程 tools/call 和 stdio 进程均受取消/超时控制 |
| LOOP-08 | P1 | 插件注册与卸载有生命周期，依赖和权限可检查；Skill 仅按需读取，执行脚本需对应工具能力 |
| LOOP-09 | P1 | 子 Agent 委派/等待/下一轮/停止统一受并发与预算约束，父子导航清楚 |
| LOOP-10 | P1 | 检查点支持失败步骤或流程节点重跑；副作用状态未知时不得盲目重放 |

验收场景：检索制度后生成文件并检查；一次工具失败后正确说明；中途停止不新增调用；嵌套材料指令不越权；旧数据迁移和重启不丢成果；付费远端创建不因重试重复提交。
