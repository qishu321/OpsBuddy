# 18 权限、安全与运行质量

## 目标

提供与文件执行、外部模型和插件能力相称的基础保护，不扩张为企业管理平台。用户普通创建成果的动作应流畅，真正具有覆盖、删除、外传或付费副作用的动作需有可理解的边界。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| SAFE-01 | P0 | 目录授权区分只读、创建新文件、修改/移动/删除；解析真实路径后校验范围 |
| SAFE-02 | P0 | 覆盖、批量移动、删除、外部发布等动作展示具体对象与影响；用户已有同范围授权可复用 |
| SAFE-03 | P0 | API Key 使用操作系统凭据保护或等效加密存储；日志、导出和模型上下文不含密钥 |
| SAFE-04 | P0 | 附件、网页、Skill、工具响应均属不可信内容，不能扩大权限或覆盖用户目标 |
| SAFE-05 | P0 | 脚本/插件在受控执行环境运行，限制目录、网络、进程、执行时长和输出大小 |
| SAFE-06 | P0 | 明示文件是否发送到云端及目标供应商；本地保存不等于本地推理 |
| SAFE-07 | P0 | 记录任务、工具、文件变更、授权、错误及费用；支持脱敏诊断包 |
| SAFE-08 | P0 | 支持每任务预算、并发与调用上限；缓存和临时目录可查看、清理 |
| SAFE-09 | P1 | 支持更细网络允许列表、插件来源校验及权限使用统计 |

## 授权体验

首次选择工作目录时说明允许的操作；当前任务已授权的创建行为不重复弹窗。涉及新目录、新供应商、新动作类型或高风险覆盖时重新检查。确认内容包括具体文件/目标、动作、预计影响，不用笼统的“允许所有操作”。

批量整理按变更计划整体确认，不必每个文件弹一次；确认后计划变更则重新核查。外部发送、发布、永久删除和无法估价的大额生成不能只凭角色或工具说明自动执行。

## 运行与隐私

权限校验必须在执行器实施，不能只依赖提示词。本地第三方进程若不能实现所需隔离，限制为用户显式信任的扩展并披露其实际访问能力；不把进程封装误称为完整沙箱。

诊断日志默认不采集全文文档；保留必要摘要、引用与错误。用户可配置日志保留周期和删除本地任务数据；删除本地数据不代表供应商端数据已删除，需真实说明边界。产品遥测默认不包含文件正文和凭据。

## 非功能验收目标

- 正常规模的本地页面交互建议 p95 ≤ 300 ms；任务提交后的可见反馈 ≤ 1 秒，不含模型完成时间。
- 长任务进度事件可持续刷新；无新进度时显示等待而非伪造步骤。
- 应用重启后可恢复未完成任务记录；写入中断不损坏原文件。
- Windows 首发版本、基准 CPU/内存、测试数据规模在测试计划中固定；以上性能指标是目标，未实测不宣称达标。
- 键盘可访问主要操作，状态不只依靠颜色表达；中文路径、文件名和常用 Office 文件纳入兼容测试。

## 必测风险场景

越权路径、目录联接绕过、恶意技能提示、日志泄钥、工具输出超量、付费接口重复提交、批量改名冲突、暂停后的子 Agent 继续调用。每项均应有可验证的阻断或恢复结果。
