# OpsBuddy 产品需求目录

版本：v0.1 草案 ｜ 日期：2026-10-14 ｜ 状态：需求规划，未代表功能已实现

## 产品方向

OpsBuddy 是面向个人和小团队的轻量 AI 工作台：用自然语言交办任务，由 Agent 调用工具处理本地文件，交付可预览、可编辑、可继续修改的成果。先做好 PPT、Word、Excel、PDF 和文件整理，再扩展多 Agent 协作及音视频创作。

参考用户提供截图中的对话与成果预览、角色卡片、工作流列表和画布交互，不照搬其庞大的企业管理菜单。不强制绑定腾讯或其他厂商账号与生态。

## 统一约定

- **P0 / R1**：首个可用版本必须完成；**P1 / R2**：增强办公、多 Agent 和生图；**P2 / R3**：视频与剪辑、进阶编排。优先级代表发布顺序，不代表后续需求可以忽略。
- 每项需求使用模块前缀编号；编号用于开发任务、测试用例和缺陷追踪。表内一个编号对应一个需求组，开发时可以追加子编号。
- “支持”表示规划目标，只有通过验收才能标记已交付。依赖供应商的能力必须在界面显示真实可用状态。
- 模型三类接口暂定为 OpenAI-compatible、Anthropic Messages、Gemini GenerateContent；具体兼容范围见第 13 章，不宣称任意兼容网关均可使用。
- 本文档是产品需求，不是 SDK/API 规范；接口字段、供应商限制、报价和授权条款应在接入时依据选定版本核实。
- 首版按 Windows 桌面客户端 + 本地任务执行器设计；跨平台、云托管与团队共享不作为首版前置条件。这是规划假设，可在实施前调整。
