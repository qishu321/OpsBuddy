# 30 模型能力与会话交互

状态：待开发补充；0.7.0 已有模型默认选择、文字回复、会话删除和运行画布，不将这些重复标为新功能。[参考与缺口](../reference-study/OpenClaw-DSH/01-功能对照.md)。

| 编号 | 优先级 | 需求与验收 |
| --- | --- | --- |
| CHAT-01 | P0 | 默认选用户配置模型，删除模型后选有效候选或引导添加；打开旧记录不切回本地整理 |
| CHAT-02 | P0 | 分别测试文本、流式、工具、视觉与结构化输出，保存测试时间和状态，不用文本连通代替全部通过 |
| CHAT-03 | P0 | 展示请求模型、服务端返回模型及 usage；缺失时显示未知；不靠身份提示或显示名称证明模型真实权重 |
| CHAT-04 | P0 | 正文渲染 Markdown 列表/表格/代码块，可复制，禁用原始 HTML 执行 |
| CHAT-05 | P0 | 流式增量、结束原因、部分回复和错误分别表示；停止后保留已收到正文并标记中断 |
| CHAT-06 | P0 | 工具轨迹与正文分层展示，直接给出实际输出、产物预览和未完成项，不要求用户只读文件名 |
| CHAT-07 | P1 | 输入草稿、引用材料和任务选项按会话保存；明确重试、分支与新任务的区别 |
| CHAT-08 | P1 | 子任务在主会话内分组，用户可查看成员与回传结果；独立会话不与内部成员混淆 |
| CHAT-09 | P1 | 画布编辑与快照节点真实可见；结果区可读，支持选择节点查看输入和输出；默认与最小窗口验收 |

保留已确认约束：Windows 桌面、Go 后端；输入框简洁；模型优先；不伪造结果，不硬编码模型自我介绍。具体供应商协议实现前核实官方规范并用协议级测试验收。
