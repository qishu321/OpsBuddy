# 异步子 Agent 协作

状态：0.4.0 第一阶段实现固定分工调度，不是任意工具调用或自主无限组队。

## 用户目标

点击派发子任务，编辑 explorer / researcher / reviewer / worker 的职责。子任务独立执行，主任务等待并统一交付。

## 功能与验收

- AGT-01 每组 1–6 位成员，执行器全局最多 3 个任务并行，10 分钟组超时。模型、角色、技能候选和知识引用在提交时冻结。
- AGT-02 explorer 探查引用文件，researcher 研究引用材料，worker 生成成果；没有联网检索或任意目录访问。每位成员是实际持久化 Task，拥有独立提示词、文件与上下文。
- AGT-03 reviewer 等待非 reviewer 成员及其追加轮完成，获得实际成果后审阅。主任务等所有成员结束后汇总，失败记录进入汇总；部分失败标为部分完成，全部失败不造汇总结果。
- AGT-04 可在运行阶段给单成员追加最多 7 轮要求；当前轮结束后带入本成员上一轮成果继续，不改变当前请求。进入最终汇总后拒绝追加，可在主会话提出后续要求。
- AGT-05 整组停止会取消排队和运行请求、阻止后续派发。已生成文件保留。桌面关闭后标为中断，不自动重复付费请求。
- AGT-06 角色名、指令、轮次、状态、子任务入口、错误与主任务均可查看；原始用户目标与成员指令保留。主任务不会把其他成员提示词直接暴露给并行成员；审阅/最终汇总按设计接收明确交付。

## 后续

由模型自主制定/扩展计划、运行中工具循环、任意成员间消息、失败检查点续跑和费用预算未实现。默认是用户可编辑的四角色计划。
