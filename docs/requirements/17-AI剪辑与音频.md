# 17 AI 剪辑与音频

## 目标与阶段

P2 将“把这些素材剪成一分钟介绍片，加字幕和旁白”转成可审阅、可重复执行的剪辑工程。先做模板与片段级编辑，不建设完整专业非线性编辑器。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| EDIT-01 | P2 | 导入视频、图片、音频和字幕；读取时长、帧率、编码、尺寸及音轨 |
| EDIT-02 | P2 | 按自然语言生成结构化剪辑计划，支持片段选择、裁剪、排序、拼接与基础转场 |
| EDIT-03 | P2 | 提供简易时间线或片段列表，用户可调整起止、顺序、总时长、画幅与字幕 |
| EDIT-04 | P2 | 支持 ASR 转写、时间戳、字幕校正及 SRT/VTT 导出；识别不确定处可复核 |
| EDIT-05 | P2 | 支持 TTS 配音、音色选择、语速、背景音乐与音量控制；只使用提供商允许的音色 |
| EDIT-06 | P2 | 支持横竖屏裁剪、图片运动、片头片尾及基础降噪，按所选处理器能力开放 |
| EDIT-07 | P2 | 支持低清预览和最终渲染，展示进度、剩余步骤、取消及错误恢复 |
| EDIT-08 | P2 | 导出 MP4、音频、字幕和 OpsBuddy 剪辑工程 JSON，记录所有源素材引用 |

## 音频独立任务

支持音频转文字、根据文本生成配音、裁剪拼接和格式转换。说话人区分为可选能力，未验证时不标识为准确身份。声音克隆、自动冒用他人音色与商业音乐授权库不纳入首期范围。

## 工程与渲染规则

剪辑工程是可复现的时间轴数据：每段记录源资产版本、源入点/出点、时间轴位置、裁剪参数、文字及音量。底层媒体处理命令由参数化执行器生成，不能拼接未转义的模型文本到 shell。

原素材只读，导出创建新文件。首次导出前展示关键剪辑计划，用户已明确授权自动制作时可以直接生成预览。字幕换行、时间对齐、画面安全区和音频削波应纳入检查。源素材被移动时提供重定位，不能静默替换为同名文件。

## 验收

- 用 3 段素材生成目标 60 秒视频，默认允许 ±1 秒误差，特殊帧率另行说明；输出可播放、无意外黑帧或静音段。
- 导出字幕与画面时间对齐；用户修改字幕后只更新工程并重新渲染，不重新执行无关生成任务。
- 输出至少验证一套明确的编码/播放器组合；不宣称所有平台通用。
- 取消渲染保留工程与有效素材，临时文件不冒充成片；磁盘不足提前提示或安全失败。

依赖：本地媒体处理器、ASR/TTS 适配器、素材管理、异步任务与运行隔离。
