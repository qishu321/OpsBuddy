# 21 知识库

更新：2026-10-15。用户明确要求将知识库作为独立功能实现，不再仅放在素材管理的后续规划里。

## 目标

把本地工作资料整理为可检索、可引用的项目知识库，为单 Agent 和工作流提供可追溯依据。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| KB-01 | P0 | 创建项目内知识库，显示说明、资料列表与索引状态 |
| KB-02 | P0 | 通过原生文件选择器导入，或引用项目资产；复制原件、识别支持格式 |
| KB-03 | P0 | 文本切片、本地索引、关键词检索；结果含文件、片段与 PDF 页码 |
| KB-04 | P0 | 查看原文切片、重建索引、移出资料；解析失败明确显示，不虚报完成 |
| KB-05 | P0 | 工作台与角色可选择知识库，执行时固定命中的原文、来源和哈希 |
| KB-06 | P0 | 提供工作流知识节点，将检索结果传给下游 Agent 并记录引用 |
| KB-07 | P0 | 项目间隔离，来源内容不成为系统指令，发送给外部模型需遵守用户授权 |
| KB-08 | P1 | 向量/混合检索、重排、大资料分页与增量索引 |
| KB-09 | P1 | OCR、独立历史版本、库级备份、团队共享与更细访问控制 |

## 验收

导入含明确费用标准的文档后检索对应主题，结果应包含真实金额及文件来源；选择该库执行任务，成果应包含命中的依据；项目外无法检索。重启后索引保留，移出文档不删除原文件，历史任务引用保持不变。知识节点接到 Agent 后应生成真正的文件。

0.3.0 已实现基础范围与当前限制详见 [使用指南](../workflows-knowledge-guide.md) 和 [实现状态](../implementation-status.md)。
