# 会话、材料与文件面板

状态：0.4.0 第一阶段实现；原生文件对话框需人工体验确认。

## 用户目标

在一个会话里引用材料、查看 Agent 结果、展开工具过程，并直接补充修改要求。左侧可切换会话 / 文件。

## 功能与验收

- SES-01 输入框左侧 + 打开材料面板，引用本机文件、文件夹、项目文件、已启用 Skill 和声明式插件技能包。
- SES-02 文件夹递归复制普通文件，原目录保留；不跟随链接；最多 16 个文件、32 MB，超限在复制前拒绝。暂不提供目录懒加载。
- SES-03 PNG/JPEG 可拖入、引用和预览。最多 4 张图进入模型视觉请求，单图 8 MB / 2000 万像素；必须选择支持视觉的实际模型并允许发送。本地模式不能识图。
- SES-04 继续发送时关联上一轮与会话 ID，带入历史摘要及上一轮成果；历史上下文保留最近 8000 字符，页面最多展示前 20 轮祖先。不是无限上下文。
- SES-05 Word 正文局部修改使用段落 ID 替换文字，不重写表格及其他 ZIP 内容，原件保留。暂不支持增删段落、修改表格、复杂域或排版控制；PPT/Excel 继续修改仍为重新生成。
- SES-06 文件面板按项目列出材料与成果，点击预览；Office 当前是内容预览。工具过程默认折叠。
- SES-07 Skill 先提供名称/说明目录，模型最多选 4 项，再读取提交时冻结的正文；记录实际读取 ID。额外产生一次模型选择请求，插件不执行任意脚本。

## 验证

Go 覆盖历史关联、无效会话拒绝、目录超限无部分导入、三类视觉载荷、Word 未修改段落/表格/样式保留。桌面自检覆盖材料面板、文件页签和历史渲染；实际供应商与 Office 排版仍需真实环境验证。
