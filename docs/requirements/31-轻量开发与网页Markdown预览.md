# 31 轻量开发与网页 / Markdown 预览

状态：0.8.0 已交付 MD / 单文件 HTML 的生成、源文编辑、预览和版本保存；多文件项目运行仍待实现。2026-10-15。服从 [当前产品方向](../product-direction.md)。保留 Go 后端和 Windows 桌面交付。

## 用户体验

在普通会话要求“做一个计算器网页” → 模型与工具生成真实 HTML 文件 → 点击成果卡片 → 桌面右侧显示可交互页面 → 切换源码或继续要求修改 → 刷新预览并保存文件。

要求“整理成 Markdown” → 生成真实 .md → 右侧显示格式化内容 → 切换源文、复制、另存 → 继续修改同一份文档。不默认转成 DOCX，不把一段聊天回复当作文件已保存。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| DEV-01 | P0 | 能生成、读取和修改 .html、.css、.js 及 .md 等常用文本文件，保留文件名和编码 |
| DEV-02 | P0 | HTML 成果提供源码/预览切换、刷新、另存；首批单文件页面支持内联 CSS/JS 和实际交互 |
| DEV-03 | P0 | .md 成果支持源文/预览、复制、保存；标题、列表、表格、引用、链接、代码块正确显示 |
| DEV-04 | P0 | 聊天正文正常渲染 Markdown，不裸露本应格式化的星号、表格源码；代码块可复制 |
| DEV-05 | P0 | 继续修改明确作用于当前文件，保留原版或可追溯新版本；预览对应实际保存的成果 |
| DEV-06 | P0 | 页面在隔离预览中运行，不获得 OpsBuddy 的 Wails 桥接、模型密钥或额外文件访问权限 |

| DEV-09 | P1 | 支持常见代码文件的基础高亮与复制；语言和运行环境的可用状态真实展示 |

## 验收样例

- HTML 计算器：产生 .html，预览中 2+3 得到 5，继续要求深色主题后页面变化；源码、保存文件与预览一致。
- Markdown 需求：产生 .md，标题、列表、表格与代码块显示正确；切回源文后原文保留，UTF-8 保存后可重开。
- Markdown 修改：只修改指定章节，未涉及内容和代码保持；新旧版本可区分。
- 文件或页面脚本不能读取模型 Key、调用桌面桥接或影响主会话；外链由用户主动打开。
- 无 HTML/MD 实际产物时不能显示文件生成成功；项目依赖或环境未准备好时明确说明，不伪造可运行预览。

## 非目标

不发布独立 OpsBuddy 网页客户端，不引入复杂云工作区、企业协作平台或完整代码 IDE。视频、会议、市场与复杂工作流不阻塞这批基础功能。
