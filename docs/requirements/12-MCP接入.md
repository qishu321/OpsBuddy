# 12 MCP 接入

## 目标与范围

通过 MCP 接入外部工具，使角色和 Agent 能使用文件处理、查询等扩展能力。MCP 是工具连接层，与模型推理接口及多 Agent 调度分别管理。

协议实现细节、版本协商、鉴权方式需在开发前对照选定版本的官方规范确认；本章定义产品支持目标。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| MCP-01 | P0 | 手动添加本地 stdio 服务和远程 Streamable HTTP 服务，分别配置启动参数或地址 |
| MCP-02 | P0 | 提供连接测试、工具发现、状态、最近错误和受控日志；不能只检测网络连通 |
| MCP-03 | P0 | 展示工具名称、说明、参数结构，按角色启用工具子集；参数在调用前校验 |
| MCP-04 | P0 | 本地进程环境变量与远程认证信息采用密钥引用，不显示明文 |
| MCP-05 | P0 | 设置超时、并发、输出大小限制与断线重连策略；区分只读和写入工具 |
| MCP-06 | P0 | 每次调用关联任务/步骤，结果经过大小限制和不可信内容处理后进入模型上下文 |
| MCP-07 | P1 | 增加资源、提示词浏览及 OAuth 接入体验；旧式 SSE 兼容按实际服务需求安排 |

## 配置与授权

本地连接展示可执行程序、参数、工作目录和环境变量名称；启动第三方服务不等于安装任意软件。远程连接展示目标域名及将发送的数据范围。首版优先支持预配置凭据；依赖尚未支持鉴权流程的服务须显示“不兼容”，不能绕过鉴权。

工具自称“只读”不自动视为可信。未知写操作按有副作用处理；调用前按实际路径、目标和动作做权限判断。发现新的工具或 schema 变化后提醒用户，不能静默扩大角色权限。

## 验收

本地与远程测试服务各完成“发现工具 → 参数校验 → 调用 → 结果追踪”。断线可恢复，只读重试受限；写入工具超时后先核查执行状态，不盲目重放。禁用服务后停止新调用，已有调用的取消结果明确可见。

依赖：进程管理、网络、凭据存储、工具注册与任务执行。
