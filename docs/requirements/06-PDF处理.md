# 06 PDF 处理

## 目标与范围

P0 处理普通文本 PDF 的阅读、提取、总结、合并、拆分和旋转；P1 增加扫描件 OCR、表格提取增强及转换。PDF 是固定版式格式，不承诺自动转换为完全一致的可编辑文档。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| PDF-01 | P0 | 识别页数、文本层和加密状态，提供分页预览 |
| PDF-02 | P0 | 提取文本、生成摘要、按问题查找内容；引用标注原始 PDF 页码 |
| PDF-03 | P0 | 按页范围拆分、按指定顺序合并、旋转和删除指定页，输出新文件 |
| PDF-04 | P0 | 输出文件页数、顺序与指定操作一致；支持抽取页面图片 |
| PDF-05 | P1 | 对扫描件执行 OCR，按页保留文本与置信提示；不确定数字提示复核 |
| PDF-06 | P1 | 表格提取到 XLSX/CSV，保留表头并标注跨页、合并单元格等风险 |
| PDF-07 | P1 | 转换 DOCX 或其他格式，说明排版可能变化，附转换后预览 |

## 流程与限制

先判断文本 PDF、扫描 PDF 或混合 PDF，再选择提取路径。P0 遇到无文本层的扫描页，应明确指出需要 OCR；不能返回空文本后声称已完成摘要。

来源页码与文件内印刷页码分开，默认使用 PDF 物理页序。加密文件仅接受用户提供的合法解密密码；密码不保存至日志。已有数字签名的 PDF 修改可能影响签名，执行前提示并另存。真正不可恢复的内容脱敏不在首版范围，遮盖矩形不得宣传为安全脱敏。

## 验收

1. 合并两份各 5 页 PDF 后得到 10 页，顺序与选择一致；再提取第 2–4 页得到 3 页。
2. 对文本 PDF 的摘要至少包含可打开定位的页码引用。
3. 混合文档准确提示哪些页未提取；启用 OCR 后，数字不确定处可追溯原页。
4. 原文件未被修改，损坏输入产生可理解的错误提示。

依赖：PDF 解析/渲染；OCR 为后续可配置本地或云端能力，云端调用需数据授权。
