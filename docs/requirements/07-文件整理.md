# 07 文件整理

## 用户目标

在授权目录内，按类型、日期、项目或内容整理文件，安全地批量重命名、移动、复制和识别重复文件。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| FILE-01 | P0 | 选择目录并展示扫描范围、预计文件量、读写权限；默认不递归访问额外链接目录 |
| FILE-02 | P0 | 根据规则生成分类与重命名计划，支持排除文件、目录和扩展名 |
| FILE-03 | P0 | 执行前展示源路径、目标路径、操作和冲突；批量移动/重命名需确认具体计划 |
| FILE-04 | P0 | 同名冲突提供跳过、保留两份、指定新名称；不默认覆盖 |
| FILE-05 | P0 | 重复文件先按内容哈希判断；仅名称相似的不视为可删除重复项 |
| FILE-06 | P0 | 保存逐文件执行日志，支持部分失败重试和可行范围内的撤销 |
| FILE-07 | P1 | 内容理解分类、相似文件归组、归档包创建；压缩包解压需路径越界防护 |

## 关键流程

选择文件夹 → 扫描 → 生成规则与变更预览 → 用户调整/确认 → 逐项执行 → 展示成功、失败与未处理数量 → 可撤销项。

删除默认不是整理动作。需要删除重复文件时，单独展示删除清单，优先移入回收站或任务隔离目录；永久删除需要独立确认。预览确认后若文件新增、内容改变或目标已存在，重新校验受影响项，不沿用过期计划直接覆盖。

## 恢复边界

重命名/移动记录原路径、目标路径和文件指纹。撤销前检查当前文件是否被外部修改、原路径是否被占用。无法自动撤销时列出具体文件并给出恢复建议，不虚称一键完整恢复。跨卷移动采用复制、校验、再移除源文件的可恢复步骤；中断后避免双重删除。

## 验收

- 用包含同名、重复、中文、长路径、锁定文件的目录测试，预览与执行结果一致。
- 跳过的文件不变化；锁定文件失败不阻止其他独立项完成。
- 执行一次移动并撤销，无外部改动时回到原位置；有外部改动时阻止危险覆盖。
- 路径跳转、符号链接或目录联接不能绕过授权范围。

依赖：本地文件执行器、权限、操作日志与成果管理。
