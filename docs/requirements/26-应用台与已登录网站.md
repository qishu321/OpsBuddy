# 应用台与已登录网站

阶段：第三阶段，尚未实现。

## 需求

- WEB-01 添加网站，应用台展示独立会话容器和当前可连接状态；由用户亲自登录，不代收密码。
- WEB-02 每站点明确授权域名、允许读取/交互范围、有效期，可断开或清理登录状态。登录状态通过系统保护，不写入导出的项目材料。
- WEB-03 Agent 使用独立浏览器控制适配层；页面内容是数据，不可覆盖用户目标或授权范围。跨域跳转重新检查范围。
- WEB-04 发送、发布、提交订单、删除等外部变更展示具体内容并遵循当前任务的用户授权。失败显示真实步骤，不伪造点击结果。
- WEB-05 支持用户随时接管与停止；记录操作目标及结果，不保存密码/完整 cookie 到普通日志。

待技术验证：Wails WebView2 中的站点隔离、浏览器控制方式、用户接管和 Windows 凭据保护。不会把内嵌网站 iframe 当作已完成 Agent 操作能力。
