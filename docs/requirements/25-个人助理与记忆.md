# 个人助理与记忆

阶段：第二阶段，0.5.1 已实现持久偏好与项目经验管理、有限引用与快照，以及应用内提醒。自动偏好候选、待办聚合和渠道身份尚未实现。

## 需求

- MEM-01 设置 → 记忆可查看、搜索、新建、修改、停用、删除个人偏好和项目经验；每条含作用范围、来源、时间、状态。
- MEM-02 自动发现偏好先作为待确认建议，不把附件中的指令自动提升为用户偏好。用户明确要求记住时直接保存，展示可撤销结果。
- MEM-03 每次任务按项目与内容相关性读取有限条已启用记忆，保存本次引用快照；停用立即影响新任务，不改写历史。
- MEM-04 个人助理将待办、关联会话、定时计划、提醒状态串联；提醒必须真实经过调度并有可查看的交付记录。
- MEM-05 渠道用户身份与本机用户映射后才允许读取个人记忆，避免群聊越界；敏感凭据不进入记忆。

验收：跨项目范围、停用/删除后不再注入、来源提示注入、记忆冲突、提醒去重和失败重发。
