# 语音输入、会议转写与纪要

阶段：第三阶段，尚未实现。

## 需求

- VOI-01 长按麦克风为语音输入，松开结束；转写结果先填入输入框，用户可编辑后发送。
- VOI-02 单击进入会议模式，显示录音状态、时长、暂停/停止和明确的录音提示，避免单击/长按误触。
- VOI-03 开始前请求系统麦克风权限，展示选择的设备与实际服务；拒绝权限或无转写服务时不能显示虚假实时文字。
- VOI-04 录音保存为材料，转写含分段时间戳，支持失败重试和手动修订；说话人分离需独立能力检测。
- VOI-05 会议结束后生成纪要、决策、行动项及来源时间；推断与原话区分，不自动发送到群聊。
- VOI-06 首版优先明确一种云端或本地 ASR 提供方，显示音频发送范围、时长/大小和费用约束。系统音频采集、跨应用会议接入另行实现。

验收：权限拒绝、设备拔出、短按/长按识别、静音/长会议、网络中断、分段去重、转写与音频时间对应、停止后设备释放。
