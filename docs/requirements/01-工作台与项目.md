# 01 工作台与项目

## 目标与范围

提供“交办任务—查看过程—预览成果—继续修改”的统一入口。P0 建设工作台、项目、历史与成果侧栏；工作流入口随对应版本启用。

## 信息架构

一级导航：工作台、项目、角色库、工作流、扩展、设置。工作台内展示最近任务；扩展内分插件、Skills、MCP；设置内分模型、文件权限、通用设置。未就绪功能显示明确状态，不占用主任务入口。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| UI-01 | P0 | 新建任务支持文本、拖入文件、选择授权文件夹、选择角色与模型；默认配置可直接开始 |
| UI-02 | P0 | 对话区展示用户需求、必要澄清、阶段进度、工具调用摘要和成果卡片；详细日志默认折叠 |
| UI-03 | P0 | 右侧成果区支持文件列表、预览、下载/另存、打开所在目录及指定成果继续修改 |
| UI-04 | P0 | 项目包含名称、说明、工作目录、任务和成果；同一项目下任务可引用指定文件，但不自动共享全部聊天上下文 |
| UI-05 | P0 | 历史支持重命名、搜索、归档、删除；删除对话与删除磁盘文件明确分开 |
| UI-06 | P0 | 运行中的任务支持停止、查看待授权操作、失败重试；切换页面不终止任务 |
| UI-07 | P0 | 支持明暗主题、键盘操作、可读错误态、空态及长任务后台状态提示 |
| UI-08 | P1 | 支持从历史消息创建任务分支；沿用输入与配置快照，不重新执行已有外部写入 |

## 关键交互

用户提交“根据这些表做月报”后创建任务卡；Agent 必要时询问统计口径；运行过程按“读取、分析、生成、检查”展示；结果以 XLSX/DOCX/PPTX 卡片呈现。用户点击某个成果输入“缩短到五页”，系统创建该成果的新版本，保留旧版本。

PPT 用逐页预览，Word/PDF 用分页预览，Excel 用工作表和单元格区域预览；图片、音视频使用相应播放器。无法预览时保留下载入口，并说明格式或组件限制。

## 边界与验收

- 空项目提供明确创建任务入口，不显示虚假统计或示例运行结果。
- 切换两个任务后输入草稿、滚动位置与当前成果选择可恢复。
- 删除历史时，未经单独选择不删除用户原文件和导出文件。
- 新任务只继承明确选择的项目配置；不能看到其他项目未授权的文件。
- 超长工具日志不挤占对话主区；用户能找到错误所在步骤。

依赖：任务执行、成果管理、角色库、模型配置。
