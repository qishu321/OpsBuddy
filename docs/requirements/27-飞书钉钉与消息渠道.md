# 飞书、钉钉与消息渠道

阶段：第三阶段，尚未实现；配置文档不代表已连接真实机器人。

## 需求

- CH-01 设置 → 连接渠道，选择飞书或钉钉，配置机器人凭据、工作区与群聊/用户白名单；密钥使用系统保护存储。
- CH-02 凭据测试、签名/时间戳校验、去重、防重放；首版传输方式按供应商官方能力确认，不提前承诺公网 webhook 或常连接均可用。
- CH-03 群聊可要求必须 @机器人；非白名单或不满足 @条件的消息不得创建任务或读取材料。
- CH-04 每条会话映射渠道身份、群/用户及项目；消息只能读取对应上下文，防止群间泄漏。
- CH-05 明确授权后才向目标发送任务结果，上传失败须有重试/失败记录；不把收到任意聊天消息当作外部发送的无限授权。
- CH-06 支持断开、暂停接收、吊销凭据和审计；配额与长消息/附件限制由适配器处理。

验收：真实机器人联调、签名错误、事件重放、白名单拒绝、@规则、跨群资料隔离、重复交付去重。未提供凭据时只能做受控 mock，不宣布已接入真实渠道。
