# 08 成果与素材管理

## 目标

让输入材料、过程文件和最终成果有明确身份、来源和版本，并可在任务间按需复用。首版不是企业知识库或同步网盘。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| ART-01 | P0 | 区分用户输入、过程产物、最终成果；卡片展示名称、格式、大小、版本和状态 |
| ART-02 | P0 | 每个成果关联项目、任务、运行、生成步骤与源文件版本；修改生成新版本 |
| ART-03 | P0 | 支持预览、下载/另存、打开目录、复制任务内引用、作为新任务输入 |
| ART-04 | P0 | 同名成果使用唯一内部 ID，导出时处理冲突；不依赖文件名关联版本 |
| ART-05 | P0 | 删除任务与清理缓存分开；用户文件不自动清理；临时文件保留策略可设置 |
| ART-06 | P1 | 素材按标签、类型和项目检索；选择指定资料后进行任务内内容检索 |
| ART-07 | P1 | 批量导出文件包及清单，包含文件版本和来源说明 |

## 存储规则

元数据与文件内容分开保存；工作区使用项目/任务隔离目录。读取用户原文件时记录位置、大小、修改时间和内容指纹；必要时创建只读快照。输入改变后恢复任务需重新校验，避免将旧分析套用新文件。

资产状态包括生成中、待验证、可用、失败、缺失。物理文件被移除时标为缺失，不能继续显示可下载。模型回复中的任意路径不能直接变成果卡，必须由执行器注册并验证。

HTML 等主动内容在受限预览中打开，默认禁用脚本、网络和本地文件访问；若未来需要交互预览，采用额外隔离环境和单独权限。预览缩略图不能替代源文件本身。

## 验收

同一文档连续修改三次，可找到三个版本并正确下载。把第二版用于新任务时引用准确，不自动取最新版。删除缓存后原文档仍存在；外部移除成果文件后界面显示缺失并允许重新生成。

依赖：文件存储、格式预览、任务元数据。
