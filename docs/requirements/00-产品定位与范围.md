# 00 产品定位与范围

> 2026-10-15 用户最新确认：轻量桌面办公与开发助手，包含网页预览和 MD 格式。以 [当前产品方向](../product-direction.md) 作为后续范围与优先级依据。下文的媒体和高级能力继续留档，但不作为首批前置需求。

核心补充：支持代码与 HTML/CSS/JavaScript 开发；网页在桌面右侧预览，MD 可生成、编辑、预览和导出。详见 [31 轻量开发与网页 / Markdown 预览](31-轻量开发与网页Markdown预览.md)。

## 目标与用户

为需要制作文档、分析表格、整理资料和创作媒体的个人及小团队，提供一个能实际执行任务并交付文件的 Agent 工作台。用户不必理解工具链或工作流节点，即可完成日常工作；高级用户可逐步配置角色、技能、插件、MCP 和模型。

核心价值：从“回答怎么做”推进到“生成结果、验证结果、按反馈继续修改”。

## 核心场景

| 场景 | 用户输入 | 期望交付 |
| --- | --- | --- |
| 周会材料 | 会议记录、数据表、现有模板 | 可编辑 PPTX、DOCX 与来源说明 |
| 表格分析 | 多份销售表、分析目标 | 清洗后的 XLSX、公式、图表和结论 |
| 资料处理 | 扫描 PDF、文本 PDF | 可检索文本、指定字段表格、拆分文件 |
| 文件整理 | 授权文件夹、分类规则 | 变更预览、整理结果、可恢复记录 |
| 内容创作 | 产品资料、参考图、目标平台 | 图片、分镜、视频及字幕素材 |
| 多人分工式任务 | “分析数据并做汇报” | 多 Agent 分工后汇总的单套成果 |

## 范围取舍

| 保留与简化 | 暂不建设 |
| --- | --- |
| 对话、项目和任务历史 | 复杂工单流转、员工在岗/考勤 |
| 角色库统一承载预设 Agent | “智能体”“数字员工”等重复入口 |
| 插件、Skills、MCP 集中在扩展中心 | 企业应用市场交易与结算 |
| 自定义模型、按任务选择模型 | 厂商专属账号体系和虚拟密钥运营平台 |
| 模板化多 Agent、后续轻量画布 | 大型 BPM、无限嵌套流程、跨组织调度 |
| 基本权限、日志、预算 | 企业级 IAM、完整合规平台与运维告警中心 |

暂不建设企业平台不意味着省略文件权限、密钥保护或任务日志；这些属于基础执行能力。

## 阶段定义

- R1：单 Agent 完成办公文件任务；具备成果预览、角色配置、自定义模型、基本 Skill/插件/MCP 接入。
- R2：模板化多 Agent、轻量工作流、生图、文档批注/OCR 增强、任务内素材检索。
- R3：AI 视频生成、自然语言剪辑、音频、进阶工作流。

首版不承诺浏览器与桌面应用的任意界面自动操作；优先使用文件处理工具和受控执行器。未来若加入 GUI 自动化，应独立定义权限与验证要求。

## 成功标准

- 用户从新建任务到找到成果，主路径不超过“输入需求 → 必要澄清/授权 → 查看交付”三个阶段。
- 首版固定验收集的 10 个办公场景全部通过；验收集见第 20 章。
- 文件可打开、格式基本正确、关键数据可追溯；不以回复文本看起来完整替代交付验证。
- 失败时能说明已完成部分、失败步骤和可继续方式；不能只显示通用错误。
- 不预设未经测试的成功率、延迟或推理成本，基线由试运行数据建立。
