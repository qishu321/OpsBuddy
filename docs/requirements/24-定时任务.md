# 定时任务

阶段：第二阶段，0.5.1 已实现基础桌面调度；关闭应用后不执行，提醒只在应用内。

## 用户流程

打开定时任务 → 设置任务要求、项目、工作目录、角色/模型、一次或重复时间 → 预览最近执行时间 → 保存。每次运行创建独立会话并关联计划与执行记录。

## 需求

- SCH-01 明确时区（默认系统时区）；支持一次、每天、每周，记录下一次触发时间。
- SCH-02 Go 持久化调度，原子抢占避免重复执行；每次独立 run ID / 会话，失败不无限重试。
- SCH-03 工作目录必须由用户原生选择，记录可访问范围；模型发送授权按计划配置，不复用其他会话的临时勾选。
- SCH-04 支持暂停、恢复、立即运行、取消、删除，保留历史会话；错过执行需明确选择跳过或补跑一次。
- SCH-05 桌面关闭时首版不执行，恢复时显示错过记录；后台常驻、开机启动、系统唤醒是独立能力，不能暗示已支持。

验收：跨时区/夏令时、重启去重、过期一次性计划、暂停竞态、运行中删除、磁盘提交失败与独立会话隔离。
