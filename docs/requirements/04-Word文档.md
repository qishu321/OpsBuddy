# 04 Word 文档处理

## 目标与范围

P0 支持 DOCX 创建、读取、摘要和结构化修改；TXT/Markdown 可作为输入。旧版 DOC、宏文档与复杂域功能不保证原样往返，应先检测并说明限制。

| 编号 | 优先级 | 需求 |
| --- | --- | --- |
| DOC-01 | P0 | 根据提纲或附件生成报告、方案、会议纪要、操作说明等 DOCX |
| DOC-02 | P0 | 支持标题层级、段落、列表、表格、图片、页眉页脚、页码及基础分页 |
| DOC-03 | P0 | 对指定章节扩写、缩写、改写、翻译或调整格式；保留未请求修改的内容 |
| DOC-04 | P0 | 支持多文档合并，处理标题编号与同名章节冲突；合并顺序可调整 |
| DOC-05 | P0 | 保存为新版本，展示修改摘要；对既有文件默认另存 |
| DOC-06 | P0 | 提供分页预览或渲染后预览；检查表格越界、孤立标题及图片布局 |
| DOC-07 | P1 | 支持目录更新、批注与修订建议；只有真实写入修订数据时才称“修订模式” |
| DOC-08 | P1 | 支持模板变量和批量生成，如根据表格生成多份通知 |

## 输入输出与交互

输入：用户要求、原文档/材料、可选模板、目标语言。输出：DOCX、预览、变更摘要；PDF 输出可作为可选转换步骤。

“把结论改得更简洁”应定位结论章节；若存在多个同名章节，展示候选定位后询问。对未知事实使用待补充标记，不自动补出不存在的客户、金额或签署信息。

## 异常与验收

- 遇到损坏、加密或无法保留的嵌入对象时，在修改前提示兼容限制，并保留源文件。
- 从会议记录生成包含标题、行动项表格与页码的文档，下载后可编辑，内容与原记录一致。
- 修改第二章后，第一章和附件内容保留；原版仍可预览与导出。
- 对含中文、长表格和图片的测试文档完成分页检查；未执行渲染检查时不能宣称排版已验证。

依赖：文档解析/生成、排版渲染、成果版本。
