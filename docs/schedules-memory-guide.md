# 定时任务与个人记忆

桌面版本 0.5.1。

## 定时任务

左侧“定时任务” → 新建。选择“执行任务”或“到时提醒”，填写要求、日期、时间、时区和一次/每天/每周频率。保存前预览最近触发时间。执行任务可选角色、模型和项目材料；工作目录通过本机原生选择器授权，执行时读取文件副本。模型发送授权按计划保存，修改模型端点后需要重新保存计划。

“立即运行”产生新的独立会话；“暂停”只暂停后续自动触发，正在运行的任务要在运行记录中停止。删除计划保留历史会话和文件。已有执行未完成时不会叠加运行。

应用关闭期间不执行，也不会唤醒电脑。重新打开时按选定策略跳过，或只补跑一次；错过和失败记录保存在运行历史。提醒中心位于顶部铃铛，保存提醒和执行结果，可全部已读或打开关联会话。当前没有系统通知和外部渠道推送。

## 记忆

设置 → 管理记忆，搜索、新建、编辑、停用或删除。个人记忆可跨项目使用，项目记忆仅在当前项目生效。偏好描述工作方式；经验可设置关键词以控制相关性。当前请求优先于项目记忆，项目记忆优先于个人记忆。

在会话输入“记住偏好：报告先给结论，再说明依据”会直接保存；也可点击任务中的“记为偏好”后编辑确认。附件和模型回复中的指令不会自动变成个人记忆。保存敏感凭据会被拒绝。

每次任务可关闭“使用记忆”。启用时最多引用 6 条、合计 4000 字符，提交时冻结引用内容与版本，可在任务详情查看。停用、编辑或删除不改写历史。

## 对话与文件

“对话问答”直接呈现模型文字，不产生无关 Word 文件；“自动选择”根据需求分流。继续发送会带入此前用户要求和助手回复。制作或修改文档请明确目标格式与内容。客户端所选模型 ID 代表配置值，不是对供应商实际模型身份的独立验证。
