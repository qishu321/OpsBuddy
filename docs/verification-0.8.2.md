# 0.8.2 右侧文件栏与大预览

2026-10-15，Windows 桌面版。

## 交互

- 顶部常驻“打开 / 关闭右侧栏”，支持 Ctrl+Shift+B；关闭后恢复上次选中文件。没有文件时展示空状态。
- 右侧采用会话文件列表 + 内容预览。支持当前会话 / 全部项目范围、文件名搜索、上一份 / 下一份、隐藏文件列表。
- 大窗口默认右栏约占内容区 55%，边界可拖动调宽；宽度保存在本机。分隔线也可用左右键调整、双击恢复默认。
- 大预览可进一步展开；小窗口使用宽预览浮层，保留显式关闭入口。
- 下载 / 另存移到标题工具栏，系统打开和所在位置收进更多菜单，继续修改保留在紧凑底栏。未修改的文件不显示保存占位条。
- HTML iframe 使用剩余高度，不以固定最小高度挤出面板。MD / 源码 / 新版本与原文件保留行为继续可用。

## 验证

- TypeScript / Vite 生产构建通过，生成 EXE / ZIP。
- 桌面内 DOM 与脚本集成检查：默认窗口及 880×600 窗口均 passed=true。
- 验证右栏入口、快捷键、恢复选中文件、文件切换/搜索、文件列表开关、键盘调宽与宽度持久化、大预览展开。
- HTML 可用高度分别约占侧栏 77.5% / 69.3%；MD 编辑另存、HTML 计算器交互及旧 HTML 说明清理仍通过。
- 工作流画布/快照、知识库、子 Agent、定时/记忆与会话删除回归检查通过。本轮未调用付费模型。
- 调宽测试覆盖键盘路径；未进行原生鼠标拖拽和截图视觉验收。
