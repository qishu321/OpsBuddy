# 网页与小游戏

交付完整 HTML 文档，CSS 与 JavaScript 内联，无第三方 CDN、外部字体或网络依赖。页面需要后端、数据库或多文件服务时，应按当前代码项目交付要求处理，不能用随机数或硬编码数据冒充接口。

根据任务实现真实交互与状态更新：游戏包含控制、计分、结束和重新开始；工具包含输入校验与结果展示。操作按钮要有可见标签，支持键盘与触摸。布局应适应窄预览与展开后的宽视图。

先保证流程可用，再统一间距、字体、对比度和反馈状态。不要用冗长说明代替功能，不让固定宽度导致主要操作超出视口。

页面在隔离 iframe 中运行，没有桌面接口，也不能访问任意网络；避免依赖 localStorage 等需要普通来源权限的机制。只返回页面源码，不加交付说明或外层围栏。未实际运行的逻辑不声称已测试。
