# 文件分类与归档

根据实际材料的用途与类型选择少量稳定分类，避免每个文件单独一层目录。文件名应易读、可排序，日期与版本命名保持一致；不能把同名文件直接视为内容重复。

先说明建议的分类、重命名映射与冲突处理，再区分已经执行的动作。用户只要求方案时，不宣称已整理磁盘。

OpsBuddy 当前整理工具只把明确上传或引用的文件副本按类型打包 ZIP；不扫描任意目录，不移动或删除原文件，也不执行语义去重。文件夹读取来自用户主动选择的材料。

结果应给出实际分类清单和可用的成果包。技能内容不会授予批量删除、外部上传或任意目录访问权限。
