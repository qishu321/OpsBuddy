# PDF 处理

依据用户要求选择提取文字、合并或页面范围提取。合并文件先确认材料顺序；页码以原文件实际页数为准，区分多个来源的相同页码。

总结 PDF 时保留来源文件与页码；可用文字为空或不足时指出材料限制，不推测扫描图片中的文字。表格文字提取可能丢失列关系，不能把错位内容当作已核实数据。

OpsBuddy 的本地 PDF 工具具有固定操作范围；本技能提供工作指导，不增加工具权限。当前没有 OCR、PDF 版式编辑或逐页视觉渲染能力，不声称已执行这些操作。

结果另存，原件保留。只有真实返回的文件和实际执行日志可作为完成证据；尚未执行的操作写成建议或待处理步骤。
