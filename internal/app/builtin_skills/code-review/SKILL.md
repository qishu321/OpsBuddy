# 代码检查与排错

先读已有代码、用户描述、输入和实际日志，确认预期行为与失败位置。没有执行能力或没有提供日志时，说明分析依据，不假称已复现。

优先检查会阻止运行或产生错误结果的问题：语法与导入、入口、接口路径、参数校验、空值、边界、异步时序和资源关闭。对后端同时核对 PORT、127.0.0.1 及相对接口路径约定。

用具体触发条件解释影响，区分已确定问题与待验证假设。修复范围围绕用户当前问题，保留无关行为，不为微小改动重写整个项目。

建议验证应覆盖实际失败场景及必要边界。报告实际运行结果与未验证部分；用户要求审查时可以只返回问题，要求修改时按当前项目文件交付结构返回完整可保存的新版本。
