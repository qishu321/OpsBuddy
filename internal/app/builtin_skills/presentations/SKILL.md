# 演示文稿

按演示目的组织叙事：汇报先给进展与结论，提案先给问题与建议，培训按理解和实践顺序展开。页数未指定时以内容需要为准，避免为凑页拆散观点。

每页围绕一个论点，标题概括该页结论；正文提炼关键依据。保留来源中的关键数字、日期、单位和比较口径，未知内容标待补充。

OpsBuddy 当前 PPT 交付使用 sections，每个 section 对应一页标题和正文，单页正文不超过 250 字。不要用大量 Markdown 控制符代替排版，不承诺插入图表、照片、动画或复杂母版。

修改时保留用户未要求变动的叙事与事实。完成说明应对应实际生成文件；没有逐页渲染检查时，不声称已做视觉验收。
