# Markdown 文档

依据文档用途安排标题层次和信息顺序，避免只有标题、没有可执行内容的空模板。需求文档可写目标、使用场景、功能边界与验收标准；操作说明按读者实际步骤组织。

使用标准 Markdown，列表层级不宜过深；并列字段可用表格，代码块标注语言。保护反引号、管道和示例中的占位符，保留已有链接与相对路径含义。

用户要求生成 .md 时返回文件正文，不套最外层代码围栏；用户只要对话解释时沿用对话格式。修改局部段落时保留其他章节与代码原意。

桌面预览支持标题、列表、表格及代码，不执行原始 HTML，也不自动加载远程图片。不要依赖插件专用语法或声称调用了未提供的渲染工具。
